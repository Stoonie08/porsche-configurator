Privacy & browser storage

Last updated: October 28, 2026

This is an independent interactive portfolio project by Stoney Jimenez. It is not affiliated with or endorsed by Porsche.

Explore without an account

You do not need an account to use this configurator. The application does not include advertising trackers, session recordings, analytics scripts, contact forms, payments, or a visitor-account database. It does not request camera, microphone, or location access.

Preferences stay in your browser

The application uses localStorage to remember the settings below. These values are read locally by the application; it does not upload them to a server. They can remain until you clear them, your browser removes them, or you use private browsing. They are not synchronized by this application.

  • Theme: your light, dark, or system appearance preference.
  • HDR environment: the selected environment filename.
  • Saved cameras: names, camera positions, targets, and fields of view that you choose to save using the camera tools.

The application does not set cookies. Browser preferences are not used for advertising or cross-site tracking. Do not put sensitive personal information in saved camera names.

Close other configurator tabs first. This removes only this project's three storage entries, not unrelated browser data. Return to or reload the configurator to use its defaults. You can also clear this site's storage using your browser settings. Clearing browser storage does not delete files you previously downloaded.

Hosting and technical requests

The site is hosted on GitHub Pages. Opening it sends normal requests for website files, including the model, images, and environments, to GitHub's hosting infrastructure. GitHub documents that visitor IP addresses are logged and stored for security purposes, even when visitors are not signed in. GitHub controls its own logs and retention; the project does not set a retention period for those logs.

See GitHub Pages documentation and the GitHub Privacy Statement for GitHub's practices and available privacy contacts.

Downloads and public assets

The browser downloads the model and other public assets to display them. Exporting camera settings creates a file on your device; the application does not upload that export. Public access is not a blanket license to reuse the project's assets. Third-party trademarks and assets remain subject to their respective owners' rights and applicable licenses.

Questions and changes

The project owner's public contact information is available on Stoney's GitHub profile. Avoid posting personal information in public issues. Using GitHub to contact the owner is subject to GitHub's own privacy practices.

This notice will be updated if the application adds services or changes how it handles information.
